# UD1 — Enunciados de práctica (resueltos)

Lista de los 19 ejercicios de práctica de la Unidad 1, **todos resueltos** (proyecto `prog-ud1`). El código de cada uno está en [[Programación/Ejercicios/UD1 - Soluciones de práctica|Soluciones de práctica]]. Enunciado fuente completo en `Anexos/` (*enunciados ejercicios prog.txt*).

- [x] **1. Nombre y saludo** — Pide el nombre y muestra un saludo personalizado. → [[Programación/Ejercicios/UD1 - Soluciones de práctica#Ejercicio 1 — Nombre y saludo|Solución]]
- [x] **2. Año de nacimiento y edad** — Solicita el año de nacimiento y calcula la edad aproximada.
- [x] **3. Operaciones con dos números** — Suma, resta, multiplicación y división.
- [x] **4. Precio con IVA** — Precio final con un 21% de IVA (ver también `Calculoiva`).
- [x] **5. Círculo** — Área (A = π·r²) y circunferencia (C = 2·π·r).
- [x] **6. Euros a dólares** — Cantidad en euros y tipo de cambio del momento.
- [x] **7. Celsius a Fahrenheit** — F = C·9/5 + 32.
- [x] **8. Metros a cm/mm/km** — Conversión a kilómetros, centímetros y milímetros.
- [x] **9. Segundos a h:m:s** — Convierte segundos a horas y minutos.
- [x] **10. Millas a kilómetros** — Distancia en millas → kilómetros.
- [x] **11. Área de triángulo** — A = ½·b·h.
- [x] **12. Promedio de calificaciones** — Promedio final de tres notas.
- [x] **13. Área de trapecio** — A = ½·(b1 + b2)·h.
- [x] **14. Perímetro de triángulo** — Suma de los tres lados.
- [x] **15. Suma de dígitos** — Suma de las cifras de un número de dos dígitos.
- [x] **16. Segundos desglosados** — Días completos, horas, minutos y segundos. *Ejemplo: 90010 s → 1 día, 1 h, 0 min, 10 s.*
- [x] **17. Descuento** — Total de compra y porcentaje de descuento → precio final.
- [x] **18. Total con impuestos** — Precio, cantidad y porcentaje de impuestos → total a pagar.
- [x] **19. Nota final ponderada** — Tres notas con sus porcentajes de ponderación.

> [!note] Estado
> Todos resueltos por el alumno. Los códigos están en el proyecto `prog-ud1` de la carpeta del curso y copiados en la bóveda.
