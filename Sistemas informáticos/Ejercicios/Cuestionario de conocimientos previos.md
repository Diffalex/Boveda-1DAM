## Preguntas (con la respuesta correcta)

1. **¿Qué es un sistema operativo?** — A) Un conjunto de programas que gestiona los recursos de hardware y software de un sistema. *(→ [[T2 - Funciones y tipos de sistemas operativos|Funciones y tipos de SO]])*
2. **¿Cuál es un SO basado en UNIX?** — B) macOS.
3. **¿Qué es una partición en un disco duro?** — B) La división lógica de un disco en unidades separadas. *(→ [[T2 - Arranque, gestores y particiones|Particiones]])*
4. **Función principal de un servidor DNS** — B) Convertir nombres de dominio en direcciones IP.
5. **¿Qué es una dirección IP?** — A) Un identificador único asignado a cada dispositivo conectado a una red.
6. **¿Qué significa RAID?** — B) Un conjunto de discos que trabajan juntos para mejorar la velocidad o la redundancia. *(→ [[T1 - Componentes hardware|Componentes hardware]])*
7. **¿Cuál NO es un sistema de archivos?** — D) HTTP (sí lo son FAT32, NTFS y exFAT).
8. **¿Qué es una máquina virtual?** — B) Un software que emula un sistema operativo dentro de otro. *(→ [[T1 - Máquinas virtuales y VirtualBox|Máquinas virtuales]])*
9. **Red para conectar dispositivos en una misma oficina/edificio** — B) LAN.
10. **Función de un cortafuegos (firewall)** — B) Bloquear el acceso no autorizado a la red.
11. **¿Qué significa HTTP?** — A) Hyper Text Transfer Protocol.
12. **¿Qué es un protocolo en redes?** — B) Un conjunto de reglas que permiten la comunicación entre dispositivos en una red.
13. **¿Qué es un servidor web?** — A) Un programa que almacena y distribuye páginas web.
14. **¿Cuál NO es un servicio de infraestructura en la nube?** — D) Microsoft Office (sí lo son AWS, Google Cloud y Azure).
15. **Comando en Linux para listar archivos** — C) `ls`.
16. **¿Qué es una VPN?** — B) Una red que permite navegar de manera anónima y segura.
17. **¿Cuál es una técnica de backup?** — B) Almacenamiento en la nube.
18. **¿Qué es una dirección MAC?** — A) Una dirección única asignada a la interfaz de red de un dispositivo.
19. **¿Qué es SSH (Secure Shell)?** — A) Un protocolo para acceso seguro a otro ordenador en una red.
20. **Comando en Windows para ver configuración de red** — B) `ipconfig`.
