# UD1 — Conectores y dispositivos

Tabla resuelta de cómo se conectan los dispositivos a la placa base (fuente: `UD1_Conectores_Dispositivos.docx` en `Anexos/`). Completa [[T1 - Componentes hardware]].

| Conector | Elemento a conectar | Cable (opcional) | Utilidad del elemento |
|---|---|---|---|
| **Conector IDE** | Disco interno IDE | Cable IDE | Conectar el disco duro IDE |
| **Slot memoria RAM DDR5** | Módulo de memoria DDR5 | — | Ampliar la memoria RAM |
| **Slot para pila CR2032** | Pila CR2032 | — | Mantener la configuración y el reloj (BIOS) |
| **Conector alimentación EATX** | Fuente ATX Standard | Cable alimentación EATX | Alimentar la placa base |
| **Slot procesador (socket LGA1366)** | Procesador Intel Core i7 | — | Instalar la CPU |
| **Slot PCI Express x16** | Tarjeta gráfica PCI Express x16 | — | Gráficos |
| **CPU FAN** | Refrigerador CPU | Cable Refrigerador → CPU FAN | Refrigerar el procesador |
| **Slot PCI** | Captura de video PCI | — | Capturar vídeo |
| **Conectores SATA** | Disco duro interno SATA | Cable SATA | Conectar discos SATA |
| **Conector M.2** | Disco duro SSD NVMe | — | Almacenamiento NVMe |
| **Conectores USB internos** | Tarjeta con puertos USB adicionales | Cables USB internos | Puertos USB extra |
| **Conector ATX 12V** | Fuente ATX Standard | Cable ATX 12V 4 pines | Alimentación de la CPU |
| **Conector Chasis Fan** | Ventilador adicional de caja | Cable ventilador chasis | Refrigerar la caja |
| **Conector CDA AUX** | Lector DVD | Cable CDA AUX | Audio interno |
| **Conectores Audio Frontal** | Conectores audio caja PC | Cables y conectores de la caja audio | Audio frontal |
| **Conector PS/2 Ratón** | Ratón PS/2 | Cable PS/2 | Conectar el ratón |
| **Conector PS/2 Teclado** | Teclado PS/2 | Cable PS/2 | Conectar el teclado |
| **Conector VGA** | Pantalla analógica | Cable VGA-VGA | Vídeo analógico |
| **Conector HDMI** | Proyector | Cable HDMI-HDMI | Vídeo digital + audio |
| **Conector Ethernet** | Switch de 24 puertos | Cable UTP Categoría 6 | Conectividad de red |
| **Puertos USB** | Memoria USB | — | Periféricos y almacenamiento |
| **Conectores AUDIO** | Auriculares | Cable 3,5 mm estéreo | Audio |
| **Conector DVI** | Pantalla TFT | Cable DVI-DVI | Vídeo digital |
| **Conector e-SATA** | Disco externo e-SATA | Cable e-SATA | Discos externos |
| **Conectores RCA Audio** | Altavoces | Cable RCA Audio | Audio estéreo |
